# Getting a key

To get an API key, create an account on the provider's developer platform, go to the API keys section, and generate a new key. The general flow is the same across providers even though the exact menus differ.

## The general steps

Across providers, getting a key follows the same shape. Sign up for an account on the provider's platform, which is usually separate from any consumer chat product they offer. Find the section for API keys or developer settings. Generate a new key, give it a name so you can identify it later, and copy it immediately, because providers typically show the full key only once at creation.

## Copy it once

Most providers display the full key a single time, at the moment you create it, and only show a masked version afterward. Copy it into your tool or a secure store right away. If you lose it, the fix is not to recover it but to generate a new one and revoke the old, which is fine and costs nothing but a moment.

## Provider notes in general terms

The major AI providers each have a developer platform with an API keys area; the labels and layout vary but the concept is identical. Some providers separate their consumer subscription from their API billing entirely, so paying for a chat subscription does not give you API access, and vice versa. Check that you are creating a key on the API or developer side, not just signing up for a consumer plan.

## One key per use where possible

Where a provider allows multiple keys, create a separate key for each tool or project rather than reusing one everywhere. Separate keys let you revoke or cap one without affecting the others, and they make it clear which tool is responsible for which usage. Naming each key by its purpose at creation makes this manageable as the number of keys grows.
