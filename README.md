# BYOK API Key Setup

A plain-language reference on bring-your-own-key setup: what an API key is, how to get one from the major AI providers, how to keep it safe, and how to set spending limits so a key cannot run up a surprise bill. Written for creators and builders who want to pay providers directly instead of through bundled tools.

## The core idea

Bring-your-own-key, or BYOK, means you create your own API key with an AI provider and plug it into the tools you use, so you pay the provider directly at their rates. Getting set up takes three steps: create an account and key with a provider, add a spending limit, and paste the key into your tool. The provider then bills you for usage and the tool charges only for its software.

## The order that matters

Set a spending limit before you use the key anywhere. The limit is the one step people skip and the one that prevents a runaway bill. Everything else is recoverable; an uncapped leaked key is the expensive mistake.
